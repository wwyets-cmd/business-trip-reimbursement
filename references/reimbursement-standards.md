# 报销标准与费用口径（部门经理及经理级以下）

> 出差人：陈建，国内营销部，山东二区域销售经理（负责鲁、浙）。标准值以公司最新制度为准，本文为已确认口径。

## 一、住宿费（元/晚，凭票）

| 城市类别 | 范围 | 单人限额 |
| --- | --- | --- |
| 特级城市 | 上海、北京、深圳、广州 | 210 |
| 省会及直辖市 | 哈尔滨、长春、沈阳、石家庄、兰州、西宁、西安、郑州、济南、太原、合肥、武汉、长沙、南京、成都、贵阳、昆明、杭州、南昌、福州、海口、乌鲁木齐、呼和浩特、银川、南宁、拉萨、天津、重庆 | 170 |
| 一类城市 | 东莞、佛山、宁波、无锡、青岛、厦门、苏州、大连 | 170 |
| 其他城市 | 上述以外所有城市 | 150 |

- **两人同住同一间房**：每晚限额在单人标准上 **+30**（例：济南单人170，同住200/晚）。
- 常见城市归类：广州=特级210；济南/杭州=省会170；宁波/佛山=一类170；德州、桂林、台州、温州、绍兴=其他150。

## 二、误餐费（按出差自然天数）

| 城市类别 | 每天 | 拆分 |
| --- | --- | --- |
| 特级城市 | 80 | 午餐40、晚餐40 |
| 其他城市 | 60 | 午餐30、晚餐30 |

- 返程当天、特殊日期由用户逐日控制（如返程半天只计30）。
- 用户会逐日指定哪些天计/不计误餐费，**严格按其口径，不自行按标准补满**。

## 三、长途交通费（凭票）

| 交通工具 | 可报席别/舱位 |
| --- | --- |
| 高铁/动车 | 二等座 |
| 火车 | 硬卧、硬座 |
| 汽车（大巴） | 凭票报销 |
| 轮船 | 二等座 |
| 飞机 | 标准上不可报销（总监及以上可报：高铁一等座、软卧、飞机经济舱，且住宿/误餐实报实销） |

- 退票手续费凭航司/平台退票凭证报销，计入产生退票的当天长途交通费。
- 飞机标准上不可报，但**用户可宣布"我给你的费用全部可报"，此时按可报处理、超标归零**。

## 四、市内交通费

- 打车等市内交通费**实报实销**；无票部分由用户单独说明后登记。

## 五、费用分类最终口径（用户原话，最高优先级）

> **"长途交通只计算高铁、飞机和大巴，顺风车和滴滴包括产生的高速费其余的计入城市交通（市内交通费）。"**

- 长途交通费 = 高铁/动车 + 飞机（含退票费）+ 大巴。
- 市内交通费 = 滴滴/快车/特快/特惠 + 顺风车 + 这些行程产生的高速费 + 充电费 + 其余市内交通。
- 注意：自驾/打车行程中产生的高速费、扫码支付的高速费，随该行程归类（通常入市内交通）。

## 六、费用大类（固定七项）

1. 长途交通费
2. 住宿费
3. 市内交通费
4. 业务招待费
5. 私车公用里程费
6. 其他费用
7. 误餐费

## 七、业务招待费

- 客户宴请、探望客户礼品等，用户明确"走招待/可以报销"后计入业务招待费；需在费用说明写明事由、对象、金额。
