# 台账工作簿结构与每日录入流程

每月一个飞书工作簿，5 张子表。新建用 `scripts/new_month_ledger.py`。

## 一、子表结构

### 1. 差旅费报销明细表（OA 差旅费报销单附件，严格按 Numbers 模板）

- 第1行信息栏：A1=部门、F1=姓名、H1=岗位。
- 第2行表头，**一天一行**，14 列 A–N：

| 列 | 字段 |
| --- | --- |
| A | 序号 |
| B/C | 起始日期 / 终止日期 |
| D/E | 起始地址 / 结束地址 |
| F | 长途交通费 |
| G | 住宿费 |
| H | 市内交通费 |
| I | 业务招待费 |
| J | 私车公用里程费 |
| K | 其他费用 |
| L | 误餐费 |
| M | 小计（公式） |
| N | 同住人 |

- M 列公式（脚本已预填 M3:M200）：`=IF(SUM(F3:L3)=0,"",SUM(F3:L3))`
- 底部"金额合计"行：F–M 各列 `=SUM(范围)`；其后为说明行、报销人/复核人/部门负责人行。

### 2. 消费台账（逐笔，15 列 A–O）

序号 / 录入日期 / 消费日期 / 城市 / 城市类别 / 费用大类 / 明细事项 / 金额 / 支付方式 / 票据状态 / 适用标准 / 可报金额 / 超标不合规 / 核对结果 / 备注。

- 每一笔消费（含无票）一行；金额 H、可报金额 L、超标 M。
- 票据状态文本中含"待"字（如"发票待开"）会被汇总页计入待补笔数。

### 3. 行程台账（逐段，14 列 A–N）

序号 / 日期 / 出发城市 / 出发时间 / 到达城市 / 到达时间 / 交通方式 / 班次席别 / 票价 / 席别是否合规 / 票据状态 / 当天计误餐 / 当晚住宿城市 / 备注。

### 4. 报销标准

整页标准表（住宿/误餐/长途/同住/凭证要求），由脚本写入，作为表内对照。

### 5. 汇总（公式自动）

- B/C/D 列按消费台账"费用大类" SUMIF：
  - B：`=SUMIF('消费台账'!$F$2:$F$500,$A2,'消费台账'!$H$2:$H$500)`
  - C：同结构，求和列 L（可报金额）
  - D：同结构，求和列 M（超标不合规）
- 第9行总计 `=SUM(B2:B8)` 等。
- B12：`=SUM('差旅费报销明细表'!$M$3:$M$200)`（与汇总总计交叉核对）。
- B13：`=COUNTIF('消费台账'!$J$2:$J$500,"*待*")+COUNTIF('行程台账'!$K$2:$K$500,"*待*")`（待补票据笔数）。
- B14：`=COUNTIF('消费台账'!$N$2:$N$500,"*超标*")+COUNTIF('消费台账'!$N$2:$N$500,"*不合规*")`。
- 误餐费只在明细表计，消费台账不录误餐费（故汇总误餐行为0，以明细表合计为准）。

## 二、每日录入流程（收截图/账单后）

1. **看图**：逐张识别日期、城市、起讫地、交通方式、金额、票据状态；看不清就放大或要求重发，不猜数。
2. **分类**：按 reimbursement-standards.md 第五部分口径归入七大类（长途只含高铁/飞机/大巴，其余含高速、充电、顺风车、滴滴入市内）。
3. **写三表**：
   - 明细表：对应日期行填 F–L、N（同住人），M 小计自动；
   - 消费台账：追加逐笔记录（序号续接）；
   - 行程台账：追加逐段行程。
4. **回读验证**：`+csv-get` 回读当天行与合计行，确认小计、分类合计、总计正确；金额用计算器核对。
5. **交付**：通过 present_files 重新交付工作簿链接（每轮改动后必交付）。
6. **三要素文字回复**（简洁不长篇）：总花费金额、行程地点、具体各项费用明细。

## 三、月末/出差结束

- 用户宣布完结后封存当月工作簿，不再改动。
- 新月用脚本新建独立工作簿；更新长期偏好中的当月台账链接。
- 如需 A5 横版凭证合订 PDF（存档/OA 附件）或合思填报，见 SKILL.md。
